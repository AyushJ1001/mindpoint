## Change control

- Never overwrite an approved ruling. Mark it `Superseded` and add the replacement with the memo version and effective date.
- Record the law, product, provider, Course, or operating change that triggered a new review.
- Keep private analysis and evidence in the secure counsel matter, not this repository.
- If the public summary and private memo conflict, stop implementation and ask counsel to issue a corrected approved summary.
- If a ruling needs missing facts, name the owner and due date. Do not treat `Needs facts` as permission.
- If counsel leaves a blocking question unresolved, keep the affected feature disabled or remove the disputed claim.
